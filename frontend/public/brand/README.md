# Cursus brand assets

Copy the six PNG files in this folder to `frontend/public/brand/`.

Required filenames:

- `cursus-logo-horizontal.png`
- `curi-welcome.png`
- `curi-student.png`
- `curi-instructor.png`
- `curi-admin.png`
- `sandbox-university.png`

All six production PNG files use real alpha transparency. Keep their aspect ratios and render them with `object-fit: contain`; do not recolor, crop, trace, or apply CSS filters.
