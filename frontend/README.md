# Cursus — AI Academic Companion (Frontend & Backend Guide)

Xem tài liệu hướng dẫn khởi chạy chi tiết đầy đủ (kích hoạt `.venv`, cấu hình `.env`, chạy FastAPI Backend & React Frontend) tại:

👉 **[docs/project/run-guide.md](../docs/project/run-guide.md)**

### Tóm tắt nhanh:
1. **Activate Python Virtual Environment (.venv)**: `.\.venv\Scripts\Activate.ps1` (hoặc `source .venv/bin/activate`)
2. **Run Backend (Port 8000)**: `uvicorn src.main:app --reload --port 8000`
3. **Run Frontend (Port 5173)**: `cd frontend && npm run dev`
