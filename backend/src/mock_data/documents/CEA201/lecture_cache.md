# Cache & Memory Hierarchy

## Hierarchy
Registers → L1/L2 cache → Main memory → Secondary storage.

## Mapping
- Direct-mapped: mỗi block memory map vào đúng 1 line cache.
- Set-associative / fully associative (khái niệm).

## Công thức ôn
Average access time ≈ hit_time + miss_rate × miss_penalty.
