# PRF192 — Programming Fundamentals with C

Chuẩn tham chiếu: C11; môi trường Dev-C++ / VS Code + GCC.

## Learning outcomes
- Viết chương trình C có cấu trúc: input/output, biểu thức, điều kiện, vòng lặp.
- Dùng hàm, phạm vi biến, pointer cơ bản.
- Xử lý mảng 1D/2D và chuỗi ký tự.
- Debug và nộp bài lab/PE đúng format.

## Outline chủ đề
1. Intro C, `printf`/`scanf`, kiểu dữ liệu, toán tử
2. Hệ đếm (binary/hex/octal) & biểu diễn số
3. if / switch
4. for / while / do-while
5. Functions, recursion cơ bản
6. Arrays 1D/2D
7. Strings & pointer intro
8. Workshop tổng hợp + PE practice

## Assessment (mock)
- Labs / Workshops: 30%
- Progress tests: 20%
- Practical Exam (PE): 50%
