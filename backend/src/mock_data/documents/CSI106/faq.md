# CSI106 FAQ

Q: Quiz Data Representation gồm gì?
A: Đổi binary↔decimal↔hex; ASCII; 2's complement; số bit cần để biểu diễn.

Q: von Neumann khác Harvard thế nào?
A: von Neumann dùng chung bộ nhớ cho instruction và data; Harvard tách riêng (khái niệm).

Q: TCP khác UDP?
A: TCP connection-oriented, reliable; UDP connectionless, nhẹ hơn.
