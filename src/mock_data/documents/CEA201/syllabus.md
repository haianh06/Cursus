# CEA201 — Computer Organization and Architecture

Tham chiếu phổ biến: William Stallings — Computer Organization and Architecture.

## Learning outcomes
- Mô tả mô hình von Neumann: CPU, memory, bus, I/O.
- Giải thích instruction cycle, datapath và control unit.
- Phân tích memory hierarchy và nguyên lý cache.
- Hiểu addressing modes, instruction formats và pipelining cơ bản.

## Outline
1. Computer evolution & performance metrics
2. System buses & interconnection
3. Internal/external memory; cache mapping
4. Input/Output modules & interrupts
5. CPU structure: registers, ALU, control
6. Instruction sets & addressing
7. Pipelining & hazards (intro)
8. OS support: interrupts, scheduling overview
