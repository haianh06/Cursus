# CSI106 — Introduction to Computer Science

Thuộc nhóm Introduction to Computing / Computer Science (CSI104–CSI106 lineage; sách nền tảng kiểu Forouzan).

## Learning outcomes
- Giải thích mô hình von Neumann và lớp phần mềm hệ thống.
- Biểu diễn dữ liệu: binary, hex, ASCII/Unicode, số có dấu.
- Mô tả thuật toán bằng pseudocode/flowchart; biết O-notation intro.
- Phân biệt ngôn ngữ máy / assembly / high-level; compile vs interpret.
- Hiểu stack mạng và TCP/IP ở mức khái niệm.

## Outline
1. What is CS? Hardware/software layers
2. Data representation
3. Boolean logic intro
4. Algorithms & problem solving
5. Programming language concepts
6. Operating systems overview
7. Networks & Internet protocols
8. Security & ethics basics
